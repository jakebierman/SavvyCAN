# SavvyCAN Scripting

1. Do not activate for ordinary GUI actions.
2. Prefer native GUI capabilities unless scripting was explicitly requested.
3. Create a draft rather than silently running or saving a script.
4. State required inputs, bounded loops and stop conditions.
5. Keep transmission subject to the same access and safety expectations as GUI
   operations.

Consult `help/scriptingwindow.md` inside the repository for the available API
and templates.
