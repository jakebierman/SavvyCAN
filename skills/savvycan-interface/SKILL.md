# SavvyCAN Interface

Use this skill for application navigation and passive CAN analysis.

1. Identify the requested workspace or visible trace operation.
2. Prefer a native SavvyCAN capability when one is available.
3. Treat filters, display formats, DBC interpretation and graphs as
   non-transmitting operations.
4. Use current GUI state for selections and enabled filters; do not invent it.
5. Use Graphify only when the question concerns source implementation or
   architecture.

Native capability schemas supplied by SavvyCAN are authoritative. Consult
`help/ai_workbench.md`, `help/payload_formatter.md`, or `help/sniffer.md` when
working inside the repository.
